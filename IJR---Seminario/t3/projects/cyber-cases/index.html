Herramientas y método

Terminal

Levanta el entorno, ejecuta perfiles controlados, consulta endpoints y conserva evidencia.

Chrome / Edge DevTools

Network, Elements, Console y Response Headers para inspección del comportamiento real del navegador.

Colab

Se utiliza para analizar archivos exportados de métricas y logs; no para atacar servicios públicos.

Git

Cada defensa debe quedar en un commit identificable para poder comparar baseline vs hardening.
