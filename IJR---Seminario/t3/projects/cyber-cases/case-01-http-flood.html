CASE 01 · APPLICATION-LAYER DOS

HTTP Flood: disponibilidad bajo presión real.

El runner genera solicitudes concurrentes reales contra /api/report. La ruta ejecuta trabajo CPU-bound y el servicio puede degradarse. El equipo debe medir, explicar y mitigar.

TerminalNginxRPSp955xxColab
Objetivo fijo: solo http://proxy dentro de la red Docker. El runner no acepta URL externa.

1. Levantar baseline

cd t3/tracks/cybersecurity/lab
docker compose up --build

En otra terminal verifica salud y métricas:

curl -i http://127.0.0.1:8080/health
curl -s http://127.0.0.1:8080/metrics

2. Ejecutar tráfico normal y ataque controlado

ATTACK_PROFILE=baseline docker compose --profile attack run --rm attack > baseline.json
ATTACK_PROFILE=flood docker compose --profile attack run --rm attack > flood-before.json

El resultado debe mostrar solicitudes reales, RPS, códigos HTTP y latencia. Conserva también los logs:

docker compose logs --no-color proxy web > incident-before.log

3. Diagnóstico

  1. Compara baseline vs flood.
  2. Identifica si sube p95, aparecen timeouts o disminuye RPS útil.
  3. Revisa qué endpoint concentra tráfico.
  4. Relaciona comportamiento del proxy con la ruta costosa.
  5. Formula una hipótesis antes de modificar código.

4. Defensa

La defensa debe implementarse en proxy/nginx.conf y/o app/server.js. Son válidas, si se justifican, medidas como rate limiting, límites de conexión, timeouts, caching para respuestas realmente cacheables o reducción del costo de la operación.

No se evalúa “poner muchas reglas”, sino demostrar qué control responde a qué evidencia.

5. Repetición experimental

docker compose up --build -d
ATTACK_PROFILE=flood docker compose --profile attack run --rm attack > flood-after.json
docker compose logs --no-color proxy web > incident-after.log

El perfil debe ser exactamente el mismo. La variable experimental es la defensa.

6. Análisis en Colab

Abre el notebook de comparación y sube flood-before.json y flood-after.json. Debes comparar RPS, p95, máximo de latencia y distribución de códigos HTTP.
