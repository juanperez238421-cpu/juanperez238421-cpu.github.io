THEORY 01

Animation is a time-dependent system

A frame is not the animation. The animation is a function of time. For an interactive visual show, each iteration reads events, updates state with elapsed time, and draws the current state.

while running:
    dt = clock.tick(60) / 1000.0
    handle_events()
    update(dt)
    draw()

dt makes motion approximately independent of frame rate. Without it, a slower computer changes the speed of the animation.

THEORY 02

Pygame vs Manim

For this project, the reference construction uses Pygame because the final requirement includes a visible launcher, live parameter changes, real-time rendering and portable execution. Manim is excellent for pre-rendered mathematical video, but it is less natural for interactive runtime behavior.

The student must still record the decision and its justification in the project README.

THEORY 03

Architecture before effects

The minimum responsibilities are separated before adding visual complexity:

  • App: window, event loop, shutdown.
  • Scene: owns the current visual composition.
  • Effect: reusable procedural behavior.
  • Config: parameters that should not be hard-coded.
  • Launcher: visible manual entry point for the portable build.
WORKSHOP

Define the product contract

  1. Create a 6–10 panel storyboard.
  2. Define resolution, target FPS and expected duration/interaction.
  3. List three visual effects that will exist in the final product.
  4. Define one live parameter that can be changed during the final defense.
  5. Write five acceptance criteria that can be tested.

Example acceptance criterion: “The application starts offline from a portable folder and shows the first scene in under 5 seconds.”

Build 01 · Create the real repository baseline

mkdir portable-visual-show
cd portable-visual-show

python -m venv .venv

# Windows
.venv\Scripts\activate

pip install pygame==2.6.1
git init

Create main.py:

import pygame

WIDTH, HEIGHT = 960, 540
FPS = 60

pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Portable Python Visual Show")
clock = pygame.time.Clock()

running = True
time_s = 0.0

while running:
    dt = clock.tick(FPS) / 1000.0
    time_s += dt

    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((18, 22, 38))

    x = WIDTH // 2 + int(180 * pygame.math.Vector2(1, 0).rotate(time_s * 70).x)
    pygame.draw.circle(screen, (224, 91, 135), (x, HEIGHT // 2), 34)

    pygame.display.flip()

pygame.quit()

Run it:

python main.py
Do not continue if the window does not open, animate and close cleanly. Fix the runtime first.
