CLASS 3 · PORTABLE BUILD

Relative paths + portable build + launcher

Today the project stops depending on the development computer. Configuration and assets must resolve through relative project paths, then the visual show is packaged into a portable build with a visible manual launcher.

pathlibJSON configrelative pathsPyInstallerlauncherportable folder
THEORY 01

Portability means no machine assumptions

Absolute paths such as C:\Users\Alejandro\Desktop\... are defects in a portable application. Runtime resources must resolve from the project/build location.

from pathlib import Path

BASE_DIR = Path(__file__).resolve().parent
CONFIG_PATH = BASE_DIR / "config.json"
THEORY 02

Configuration is data, not code

Parameters used during the final defense should live in a small config file. This makes the visual behavior inspectable and editable without touching algorithms.

{
  "width": 960,
  "height": 540,
  "fps": 60,
  "particle_count": 120,
  "orbit_speed": 1.4
}
THEORY 03

Packaging changes runtime paths

PyInstaller can bundle Python and dependencies into an executable. The application still needs a robust resource path function for both source mode and packaged mode.

import sys
from pathlib import Path

def resource_path(relative):
    if hasattr(sys, "_MEIPASS"):
        return Path(sys._MEIPASS) / relative
    return Path(__file__).resolve().parent / relative

Build 01 · Load config safely

import json
from pathlib import Path

def load_config(path: Path):
    defaults = {
        "width": 960,
        "height": 540,
        "fps": 60,
        "particle_count": 120,
        "orbit_speed": 1.4,
    }

    if not path.exists():
        return defaults

    try:
        user = json.loads(path.read_text(encoding="utf-8"))
    except (OSError, json.JSONDecodeError):
        return defaults

    return {**defaults, **user}

Test three states: valid config, missing config, malformed JSON. The application must fail gracefully or use documented defaults.

Build 02 · Visible launcher

Create launch.bat:

@echo off
cd /d "%~dp0"
echo Starting Portable Python Visual Show...
start "" "PortableVisualShow.exe"

The launcher is intentionally visible and manual. No autorun, hidden tasks or permanent system changes are required.

Build 03 · Package

pip install pyinstaller==6.16.0

pyinstaller ^
  --noconfirm ^
  --clean ^
  --onefile ^
  --name PortableVisualShow ^
  main.py

Copy the executable, config, launcher and README into a new folder named PORTABLE_BUILD. If external assets are introduced, include them explicitly and verify their relative paths.
