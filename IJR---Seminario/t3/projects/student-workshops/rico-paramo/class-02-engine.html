THEORY 01

Frame-rate independence

Movement should be expressed in units per second, not units per frame.

# wrong
x += 3

# correct
x += velocity_px_per_s * dt

At 30 FPS and 120 FPS, the second form preserves approximately the same physical speed.

THEORY 02

Procedural animation

Instead of playing a pre-made asset, the visual state is generated from equations and parameters. Useful building blocks include sine waves, polar motion, interpolation, random fields and deterministic seeds.

x = cx + radius * cos(omega * t + phase)
y = cy + radius * sin(omega * t + phase)
THEORY 03

Reusable effect contract

Each effect should expose a stable interface. That lets one scene combine different implementations without knowing their internal equations.

class Effect:
    def update(self, dt: float) -> None:
        ...

    def draw(self, surface) -> None:
        ...
WORKSHOP

Three effects, three responsibilities

  1. OrbitEffect: circular/polar motion.
  2. PulseEffect: radius/alpha driven by sine.
  3. ParticleField: multiple generated elements with deterministic seed.
  4. Expose speed, amplitude, color and count as parameters.
  5. Change one parameter without editing the effect algorithm.

Build 01 · Convert the loop into App + Scene

class Scene:
    def __init__(self, width, height):
        self.width = width
        self.height = height
        self.time_s = 0.0

    def update(self, dt):
        self.time_s += dt

    def draw(self, surface):
        surface.fill((18, 22, 38))


class App:
    def __init__(self):
        pygame.init()
        self.screen = pygame.display.set_mode((960, 540))
        self.clock = pygame.time.Clock()
        self.scene = Scene(960, 540)
        self.running = True

    def run(self):
        while self.running:
            dt = self.clock.tick(60) / 1000.0

            for event in pygame.event.get():
                if event.type == pygame.QUIT:
                    self.running = False

            self.scene.update(dt)
            self.scene.draw(self.screen)
            pygame.display.flip()

        pygame.quit()

Build 02 · First reusable effect

import math
import pygame

class OrbitEffect:
    def __init__(self, center, radius=150, speed=1.2, color=(235, 90, 140)):
        self.center = pygame.Vector2(center)
        self.radius = radius
        self.speed = speed
        self.color = color
        self.t = 0.0

    def update(self, dt):
        self.t += dt

    def draw(self, surface):
        x = self.center.x + self.radius * math.cos(self.speed * self.t)
        y = self.center.y + self.radius * math.sin(self.speed * self.t)
        pygame.draw.circle(surface, self.color, (int(x), int(y)), 22)
