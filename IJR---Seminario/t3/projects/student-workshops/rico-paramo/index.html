CLASS 2 · PROCEDURAL ENGINE

Animation engine + reusable effects

NOT COMPLETE

Turn the baseline into a frame-rate-independent procedural engine with reusable effect classes and parameter-driven behavior.

Theory

  • Use delta time so motion is expressed in units per second.
  • Separate update(dt) from draw(surface).
  • Use procedural equations and parameters instead of duplicated drawing code.
  • Use deterministic random seeds for reproducible particle state.
dt = clock.tick(fps) / 1000.0
x += speed_px_s * dt

Workshop

  • Refactor into VisualApp and VisualScene.
  • Implement OrbitEffect, PulseEffect and ParticleField.
  • Instantiate one effect with different parameters.
  • Compare behavior at 30 FPS and 120 FPS.
  • Restart with a fixed seed and verify the same initial layout.
OrbitEffectsin / cos · radius · speed
PulseEffectperiodic scale / alpha
ParticleFieldseeded particles · reproducible state
CLASS GATE 02The same effect class is reusable with different parameters and motion remains approximately consistent across frame-rate changes.

CLASS 3 · PORTABLE BUILD

Relative paths + portable build + launcher

NOT COMPLETE

Remove development-computer assumptions, externalize parameters and package the visual show so it survives relocation and offline execution.

Theory

  • Absolute paths are machine-specific portability defects.
  • Visual parameters belong in external JSON configuration.
  • Packaged runtime resource lookup differs from source execution.
  • Packaging is not proof of portability; the moved build must execute.

Workshop

  • Create config.json with safe defaults/fallbacks.
  • Resolve assets relative to the runtime location.
  • Build PortableVisualShow.exe with PyInstaller.
  • Create a visible manual launch.bat and README.
  • Copy/rename the folder, disconnect the network and run again.
pyinstaller --noconfirm --clean --onefile --name PortableVisualShow main.py
PORTABLE_BUILD/├─ PortableVisualShow.exe├─ config.json├─ launch.bat├─ assets/└─ README.txt
CLASS GATE 03The copied/renamed build launches manually with the network disconnected and without absolute developer paths.
