Animated Message Studio

Construye por código un mensaje animado completo: fondo dinámico, partículas, flores que crecen, corazón paramétrico, texto y render MP4. El proyecto está dividido en módulos reales para trabajar desde Terminal o Google Colab y termina con una entrega preparada para USB.

PythonPillowNumPyImageIOFFmpegTerminalColabUSB
Código completo Notebook Colab Volver a Projects
Ejemplo base: “Para ti — Un mensaje hecho con Python”. El estudiante debe modificar diseño, timings y elementos; cambiar únicamente el texto no constituye un proyecto terminado.

Cada frame se calcula en Python. No es una grabación de pantalla: el programa genera píxeles, compone capas RGBA y entrega los frames al encoder de video.

Terminal · render definitivo

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

python run.py --title "Para ti" --subtitle "Un mensaje hecho con Python" --out output/animated_message.mp4 --width 1280 --height 720 --fps 30 --seconds 8

Salida esperada: video H.264 de 8 s a 30 fps. Para pruebas rápidas puede usarse una salida GIF pequeña.

Colab · misma arquitectura, entorno reproducible

El notebook instala dependencias, clona el repositorio, ejecuta cada módulo y reproduce el MP4 final dentro de Colab. No es una versión simplificada: utiliza el mismo paquete Python.

Idea USB · entrega final

El USB funciona como producto final y evidencia técnica. Se propone incluir el MP4 terminado, un ejecutable Windows generado con PyInstaller y un README. Windows moderno normalmente no permite autorun desde USB, por lo que la presentación correcta es mediante doble clic.

usb\build_windows_usb.bat
USB_PACKAGE/
  animated_message.mp4
  AnimatedMessage.exe
  README_USB.txt
